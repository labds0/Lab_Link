# Lab Link

ثلاث حتت:
- `worker/` السيرفر (Cloudflare Worker + KV + R2 لملفات الـ PDF)
- `desktop/` برنامج المعمل على Windows (Electron)
- `mobile/` نسخة المريض (موقع PWA بيتثبت على الموبايل)

## 1) تشغيل السيرفر (مرة واحدة)
```
cd worker
npx wrangler login
npx wrangler kv namespace create DATA        # الصق الـ id في wrangler.toml
npx wrangler r2 bucket create lab-results-files
npx wrangler secret put SECRET               # أي نص عشوائي طويل
npx wrangler secret put ADMIN_KEY            # كلمة سر الأدمن (إنت بس) للوحة التفعيل
npx wrangler deploy
```
هيطلع لك رابط زي `https://lab-results-api.xxx.workers.dev`.

## 1-ب) تفعيل المعامل بسيريال الجهاز
كل معمل = كمبيوتر واحد، والتفعيل مرتبط بالكمبيوتر نفسه (مش بالإنترنت ولا الـ IP):
1. المعمل يفتح البرنامج أول مرة، فتظهر له شاشة "رقم الجهاز" (زي `A1B2-C3D4-E5F6-0718`) ويبعتهولك.
2. إنت تفتح `admin/index.html` من جهازك، تدخل رابط السيرفر و`ADMIN_KEY`، وتكتب رقم الجهاز واسم المعمل ورقم الفرع، فيطلع لك **كود التفعيل** (زي `K7M2-9QXA-4TPD`). ابعته للمعمل.
3. المعمل يكتب الكود فيتفعل الجهاز، وبعدها يدخل بـ **admin / 1234**.
4. من **الإعدادات** يغيّر اسم المستخدم وكلمة السر، ويضيف مستخدمين تانيين (مدير أو موظف)، ويعدّل بيانات المعمل.

- الكود ثابت لكل سيريال، ولو ضاع تطلعه تاني من نفس اللوحة. لو كتبه على جهاز تاني مش هيشتغل لأن الكود مشتق من السيريال.
- الجلسة (التوكن) مربوطة بسيريال الجهاز، فلو اتنسخت لجهاز تاني بتترفض.
- "إيقاف" في اللوحة بيوقف الجهاز فورًا ويقدر يرجع بـ "تشغيل" وبياناته محفوظة. "إرجاع admin/1234" لو المعمل نسي كلمة سر المدير (مفيش إيميل ولا استرجاع تلقائي).
- مهم: `SECRET` هو اللي بيتولد منه كود التفعيل، فماتغيّروش بعد ما تبدأ تفعّل أجهزة، وإلا الأكواد القديمة هتتغير.
- السيريال مشتق من **الهاردوير**: سيريال اللوحة الأم (Motherboard) + سيريال هارد النظام (اللي عليه C:). فبيطلع **نفس الرقم** حتى لو الويندوز اتفرمت أو اتثبّت من جديد أو البرنامج اتحذف وانزل تاني.
  - لو سيريال اللوحة وهمي (مكتوب فيه "Default string" أو "To be filled by O.E.M.") بنستخدم رقم الجهاز من الـ BIOS بداله.
  - لو القراءة فشلت مرة (نادر) البرنامج بيستخدم آخر سيريال كامل متخزن بدل ما يتغير فجأة.
- السيريال بيتغير بس لو **اتغيّرت اللوحة الأم أو هارد النظام** (أو اتنسخ الهارد على هارد جديد). ساعتها المعمل يبعتلك السيريال الجديد وإنت تضغط **"نقل لسيريال جديد"** في اللوحة: بيانات المعمل والمستخدمين والمرضى والنتايج بتفضل زي ما هي، والمعمل بس يكتب كود التفعيل الجديد.
- محاولات كود التفعيل الغلط بتتقفل 15 دقيقة.

## 2) ربط الرابط
حط رابط الـ Worker في ملفين:
- `desktop/app-config.json` (API_URL، وتقدر تغير APP_NAME)
- `mobile/index.html` (ثابت API_URL في أول السكريبت)

وبدّل اللوجو: `desktop/renderer/logo.svg` و `icon.png` (256×256) و `mobile/logo.svg` و `icon-512.png`.

## 3) بناء برنامج Windows وتحديثه بدون حذف
ارفع المجلد على GitHub وضيف في Settings ← Secrets: `CLOUDFLARE_API_TOKEN` (صلاحية Workers R2 Storage Edit) و `CLOUDFLARE_ACCOUNT_ID`.

**أول نسخة:** Actions ← **Build Windows app** ← Run workflow، ونزّل `LabLink-Setup-1.0.0.exe` من Artifacts ونصّبه عند المعامل. (محليًا: `cd desktop && npm install && npm run dist`).

**إصدار تحديث:** اعمل tag بنسخة أعلى:
```
git tag v1.0.1
git push origin v1.0.1
```
الـ workflow بيبني النسخة ويرفعها على السيرفر لوحده. أي برنامج مثبت بيفحص التحديث عند التشغيل (وفيه زر "التحقق من تحديث")، فيظهر "يوجد إصدار جديد" ← "تحديث الآن" ← "إعادة التشغيل وتثبيت". التثبيت بيتم فوق النسخة الحالية من غير حذف، وبيانات المعمل والمستخدمين محفوظة في السيرفر.

> ملف التنصيب مش موقّع رقميًا فويندوز ممكن يطلع تحذير SmartScreen أول مرة. التحديث نفسه بيشتغل عادي.
> نسخة الموبايل بتتحدث لوحدها: كل ما ترفع تغيير على `mobile/` وتشغل Deploy mobile، المريض بياخد الجديد عند فتح الرابط.

## 4) نسخة الموبايل
في GitHub: Settings ← Pages ← Source = **GitHub Actions**، وبعدها شغّل **Deploy mobile**.
المريض يفتح الرابط ويعمل "Add to Home screen".

## طريقة الاستخدام
1. المعمل يفعّل الجهاز بالكود ويدخل بـ admin / 1234 (ويغيّرهم من الإعدادات).
2. "+ مريض جديد" ← بيطلع كود من 6 أرقام وكلمة سر (بتظهر مرة واحدة، فيه زر طباعة).
3. اختار المريض من القايمة ← "إرفاق نتيجة PDF" (تقدر تختار أكتر من ملف).
4. المريض يدخل من الموبايل بالكود وكلمة السر ويشوف نتايجه هو بس.

## الأمان (اللي اتعمل)
- كلمات السر متخزنة مشفرة (PBKDF2)، ومفيش حد يقدر يشوفها حتى المعمل (فيه "كلمة سر جديدة").
- المريض مايشوفش غير ملفاته، والمعمل مايشوفش غير مرضاه.
- قفل 15 دقيقة بعد 5 محاولات دخول غلط.
- كلمة السر الجديدة 6 أحرف على الأقل (الافتراضية 1234 بس استثناء، وبيظهر تنبيه لحد ما تتغير).
- بيقبل PDF فقط وحد أقصى 20 ميجا للملف.

## ملاحظات
- مفيش تسجيل بالإيميل خالص، ولا "نسيت كلمة السر" تلقائي: لو المدير نسي، إنت ترجعه من اللوحة.
- كل جهاز له مرضاه ومستخدميه الخاصين (معزول عن باقي المعامل).
